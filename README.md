# What is this?
These are Terminal customization files made for my CLI video.

## How to use
1. Simply put `starship.toml` in your home directory or in your `.config` directory.
2. Add `fastfetch` to `~/.bashrc` or your shell script file.
4. Put `config.jsonc` in `~/.config/fastfetch`
5. I put `saturn.txt` in `~/Documents`. If you want to put `saturn.txt` anywhere else, make sure to change the path in `config.jsonc`

OR

1. Use the convenient `install.sh` bash script.
